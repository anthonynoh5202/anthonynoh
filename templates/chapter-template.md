## 1. 원리

왜 생기는지 근본 원인을 설명한다. 그림이 필요하면 ASCII 다이어그램이나 mermaid를 쓴다.
"신뢰 경계(trust boundary)"가 어디에서 깨지는지 반드시 짚는다.

## 2. 발생하는 코드 패턴

실제 코드로 보여준다. 언어별로 가장 흔한 형태 1~3개.

```python

...
```

```python
# ✅ 안전
...
```

## 3. 탐지 방법

### 3.1 코드 리뷰 / 정적 분석
- grep 패턴, Semgrep 룰, CodeQL 쿼리 중 하나 이상
- 무엇을 보면 의심해야 하는지

### 3.2 동적 테스트
- 입력값과 기대 반응
- 자동화 도구와 수동 확인의 역할 분담
